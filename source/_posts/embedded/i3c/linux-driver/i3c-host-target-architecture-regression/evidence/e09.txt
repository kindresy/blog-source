# I3C 软件触发外设复位、旧动态地址隔离与业务恢复实验报告

实验日期：2026-10-13。Host：i.MX93/Linux；Target：Current Proj EMU/baremetal。实验入口：独立 `swreset`，复位前后各运行一次 AUTO table1；不是 full 33 步或 RSTACT01 测试。

## 1. 结论与验收范围

**本轮软件观测范围内，外设复位、旧地址隔离及业务恢复双端通过。** 复位前 run=25712、generation=1、DA=`0x30`；复位后 run=39141、generation=2、DA=`0x31`。两轮 Host 均为 `HOST_PASS`，Target 均为 `LOCAL_PASS`，各完成 4/4 步。

| 验收点 | 实测证据 | 判定 |
| --- | --- | --- |
| 复位前数据与事件通路 | Write4、Read4、IBI4、GETSTATUS；两端 run=25712 通过 | PASS |
| 旧 TX 已发布后允许复位 | STAGED：`free=0x00040004 cmd=0x00010001 length=0x00040000`，随后 BEGIN | PASS，修复 free=4 的误拒绝 |
| 复位原始状态 | 配置 IP 前：`ctrl=0 addr=0x00008044 rx=0 response=0 ext_free=0x00040004 ext_cmd=0 intr=0` | PASS，DA 有效位和待发命令清除 |
| 重新开启且尚未枚举 | `generation=2 enable_ack=1 da_valid=0 state=WAIT_DA` | PASS |
| 重新枚举前旧地址隔离 | 对 `0x30/W`：`NACK stop=idle payload=0` | 软件判断 PASS；波形待补 |
| 重新枚举及迁移地址 | 直接 ENTDAA，Host epoch 2→3；Linux 先恢复 `0x30`，随后 SETNEWDA 到 `0x31` | PASS |
| 新地址建立后旧地址隔离 | 再探测 `0x30/W`：`NACK stop=idle payload=0` | 软件判断 PASS；波形待补 |
| 新业务不受旧 TX 污染 | 两端 run=39141 通过；Host 实收 `11223344`，不是 `d1d2d3d4` | PASS |
| 最终状态 | IDLE、enumerated=1、DA31、generation=2、RX/response=0、last_error/cleanup_error=0 | PASS |

原验收方案包含两次旧地址 NACK 的外部波形，当前未提供，因此**完整波形验收仍待补齐**。这里不宣称 FIFO 物理存储的每一位均被清零；证据是复位后的队列/命令状态与正确的新数据读回。未覆盖传输中途强制复位、CPU/SRAM/SoC 复位、`RESET_CTRL[0]`、RSTACT 动作、旧 Host 句柄/请求队列隔离，或新自动化路径。
